# 人工智能代理学习站

> 一份面向中文读者的 AI Agent（人工智能代理）系统学习路线。从“什么是大模型”到“亲手做出能干活的多智能体”，按工程落地的真实顺序组织，不堆概念、不灌鸡汤。

这份资料的目的很单纯：把你从“听说过 Agent”带到“能独立设计、搭建、部署一个生产可用的智能体系统”。它不绑定任何一家商业课程，也不夹带任何推广，所有内容都可以在本地复现。

## 这份资料适合谁

- 想系统入门 AI Agent 的开发者、学生、产品经理。
- 已经会用 ChatGPT / 文心一言，但说不清“Agent 和聊天机器人差在哪”的人。
- 团队里被推去落地大模型应用，却没人带、只能自己摸黑的人。

## 这份资料不适合谁

- 想找一个“包就业、保offer”的捷径——这里没有，也不可能有。
- 只想复制粘贴代码、不想理解原理的人。Agent 系统的坑都在边界情况里，不懂原理迟早踩。

## 学习路线（六段式）

1. **认知与基础** —— 大模型是什么、提示词怎么写、RAG/微调/Agent 怎么选（1-1 ~ 1-3）
2. **知识库与低代码平台** —— 先用手边的工具把东西做出来（2 ~ 6）
3. **工程化部署** —— Docker、Ollama、企业级服务（7 ~ 8）
4. **LangChain 框架** —— 用代码把能力串成流水线（9 ~ 19）
5. **LangGraph 与多智能体** —— 当单条流水线不够用时（20 ~ 26）
6. **进阶与实战** —— Skills、微调、真实项目（27 ~ 28 + 实战项目）

每一章都可独立阅读，但强烈建议顺着编号走，因为后面的章节默认你已懂前面的概念。

## 怎么用这份资料

本站是一个 [docsify](https://docsify.js.org/) 文档站：

- 本地预览：在仓库根目录执行 `npx docsify-cli serve .`，浏览器打开 `http://localhost:3000`。
- 或直接访问仓库的 GitHub Pages。
- 想边读边改？`git clone` 下来，改完提 PR 即可（见 CONTRIBUTING.md）。
