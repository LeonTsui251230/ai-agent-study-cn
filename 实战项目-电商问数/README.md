# 实战项目：电商问数 Agent

**目标**：运营用自然语言提问（如“上周销售额 Top 5 的品类”），Agent 自动生成 SQL、查库、出图表与结论。

## 为什么做它

“用自然语言查数据库”是 BI 场景的刚需，也是 Agent + 工具 + 结构化输出的典型练手。

## 能力设计

1. **意图转 SQL**：模型把问题转成 SQL（用输出解析器拿结构化语句）。
2. **执行**：在受控只读库上跑，禁止写操作。
3. **可视化**：把结果转成图表（用绘图库）。
4. **解释**：用中文说明“为什么涨/跌”。

## 安全红线

- 只允许 `SELECT`，SQL 注入与写操作一律拦截。
- 数据库账号用只读权限，且与生产账号隔离。

## 文件

- `text2sql.py`：问题→SQL 的提示词与解析。
- `query.py`：受控执行。
- `chart.py`：结果绘图。
- `run.py`：入口。

> 教学示例，请使用脱敏后的样本库，切勿接生产库。
