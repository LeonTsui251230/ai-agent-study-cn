# 实战项目：深度研搜 Agent

**目标**：给定一个问题，Agent 自动检索多篇资料、交叉验证、产出一份带引用的综述报告。

## 为什么做它

“搜资料 + 写综述”是知识工作者的高频苦活。把它做成 Agent，能体会工具调用 + 循环 + 反思的完整链路。

## 能力设计

1. **规划**：把大问题拆成 3~5 个子问题。
2. **检索**：对每个子问题调用搜索工具（MCP / 自写工具）。
3. **核验**：对比不同来源，标记冲突点。
4. **撰写**：综合成结构化综述，每条结论附来源。

## 运行（示意）

```python
from lib.model_client import get_chat_model
# 见本目录 agent.py：用 LangGraph 编排 规划→检索→撰写 三个节点
```

## 文件

- `agent.py`：LangGraph 图定义（规划/检索/撰写节点 + 条件边）。
- `tools.py`：搜索工具封装。
- `run.py`：入口，读问题、跑图、打印报告。

> 教学示例，搜索工具请替换为你有授权的数据源。
